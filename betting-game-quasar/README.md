### Quasar Dev
Create Quasar
```
$npm init quasar@latest
```
Quasar Recommended
```
- Javascript
- Composition API with <script setup>
- Do not setup SCSS
- Pinia
```
Run Quasar Dev
```
$quasar dev or $npm run dev
```
Pinia Store
```
$quasar new store <store-name>
```
